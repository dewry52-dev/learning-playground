# 몽글몬 원정대 — 로컬 시제품

배포하지 않고 이 컴퓨터에서 실행하는 초3 곱셈·나눗셈 게임입니다. 외부 서비스·패키지 설치·이미지 다운로드가 필요 없습니다.

## 실행

이 폴더에서 `node server.cjs` 실행 후 http://127.0.0.1:5193/ 에 접속하세요. 종료하려면 실행한 터미널에서 Ctrl+C를 누르세요. 다시 시작하려면 같은 명령을 실행하세요. `실행.cmd`를 더블클릭해도 됩니다.

## 사용

- 개인 모험: 계산 유형을 선택하고 정답 5개를 맞히세요. 오답 벌점과 시간제한은 없습니다. 나눗셈은 나머지가 없으면 0을 입력합니다.
- 협동: 선생님 화면에서 방 생성 → 학생 참여용 새 탭 열기 → 새 탭에서 코드로 참여 → 원래 탭에서 시작. 학생 정답이 공동 체력에 반영됩니다. 같은 컴퓨터의 다른 브라우저에서도 코드로 참여할 수 있습니다.
- 현재 서버는 보안을 위해 127.0.0.1에만 연결합니다. 다른 태블릿에서 직접 접속할 주소가 아니며 인터넷에 배포하지 않았습니다.
- 개인 진도는 브라우저 저장소에만 남습니다. 초기화 버튼으로 지울 수 있습니다.
- 협동방은 메모리에서만 유지됩니다. 주최자가 종료하거나 생성 2시간이 지나면 방/참가/문제/제출 상태가 삭제됩니다. 서버 재시작 시에도 사라집니다. 서버는 학습 답안 로그를 남기지 않습니다.
- 보스 격파 후에도 교사가 방 종료 버튼을 눌러 기록을 지워 주세요. 창을 닫는 것만으로 즉시 종료되지 않으며 최대 2시간 뒤 자동 정리됩니다.

## 검증

`node test.cjs`로 유형별 산술 생성, 나머지 검증과 실제 HTTP 협동 흐름·동시 답·권한·중복 공격·종료 삭제를 검사합니다. 실제 학교 태블릿과 교과서 유형 대조는 별도로 확인해야 합니다.

정답 서버 판정과 방장 권한을 포함한 시제품입니다. 공개 배포 전에는 실제 운영 환경에 맞춘 호출 제한·세션 정책·학교망·기관 정책 점검이 필요합니다.
