# 배움 팝! — 학생용 학습 놀이터

초등 5학년 약수·배수 게임. 총 10문제, 시간제한 없음, 한 문제 10점.
로그인·이름 입력·결과 저장·외부 API 호출이 없습니다.

## 실행
이 폴더에서 다음 명령을 실행하고 터미널을 유지하세요.

```powershell
node server.cjs
```

브라우저 주소: http://127.0.0.1:5180/

서버를 종료했거나 PC를 다시 시작했다면 위 명령으로 다시 실행하세요.
이 주소는 현재 PC의 미리보기용이며 학생 태블릿에 배포한 주소가 아닙니다.
Codex의 네트워크 제한 환경에서는 브라우저가 서버에 접속할 수 없으므로 로컬 네트워크 접근이 가능한 실행 환경에서 서버를 시작해야 합니다.

## 구조
- index.html: 허브·소개·게임·결과 화면
- style.css: 태블릿 반응형 디자인
- programs.js: 프로그램 카드 목록
- math.mjs: 문제 생성·채점·풀이
- game.js: 화면 전환과 게임 상태
- server.cjs: 로컬 미리보기 서버(5180번 포트)
- test.mjs: 산술·생성·중복 제출 자동 검증
- previous-prototype/: 수정 전 시제품 보관

새 게임은 programs.js에 항목을 추가하고 route와 연결할 화면·게임 모듈을 구현합니다.
문제 범위는 math.mjs의 createRound에서 수정합니다.
게임 상태는 메모리에서만 유지하며 새로고침·재도전·놀이터 복귀 시 사라집니다.

## 검증
`node test.mjs`: 1,000판 / 10,000문제의 개수·범위·보기 중복·정답 수·산술·중복 제출·점수를 검사합니다.
복구 후 서버의 HTML과 math.mjs 모두 HTTP 200 응답을 확인했습니다.
실제 학교 태블릿의 화면·접근성·전체 게임 흐름은 추가 확인이 필요합니다.

## PDF 글자 수 도구
허브의 **PDF 글자 수 세기** 카드 또는 `/pdf-counter/`에서 실행합니다.
- PDF.js 6.4.299 및 한글 PDF용 CMap을 `pdf-counter/vendor/`에 포함했습니다. 외부 CDN이 필요하지 않습니다. 라이선스는 vendor/LICENSE입니다.
- PDF는 File API로 메모리에 읽고 Web Worker에서 분석합니다. 서버로 PDF, 이름, 본문, 결과를 전송하지 않으며 저장소도 쓰지 않습니다. 서버는 GET/HEAD만 허용합니다.
- 공백 포함/제외 글자 수, 페이지 수, 페이지별 집계와 추출 텍스트를 제공합니다. Unicode grapheme 단위, NFC 정규화, 줄바꿈/탭은 공백으로 집계합니다. 페이지 가장자리 공백은 제거하고 페이지 구분자는 집계하지 않습니다.
- 한 번에 1개, 최대 50MB. 스캔 PDF는 OCR 미지원이며, 글자가 없는 페이지는 경고합니다. 암호 PDF는 해제한 사본이 필요합니다.
- 파일과 결과 지우기, 페이지 이탈, 새로고침 시 앱의 데이터 참조를 제거합니다. 메모리의 물리적 삭제 시점은 브라우저가 관리합니다.
- 브라우저 검증: 허브 이동, 실제 PDF 14/12자 집계, 외부/업로드 요청 없음, 초기화, 손상 파일 안내, 390px 화면 너비 통과. 기존 수학 게임 1,000판 검증도 통과했습니다.
- 기본 포트가 사용 중이면 PowerShell에서 `$env:PORT='5182'; node server.cjs`로 다른 포트를 지정할 수 있습니다.

## 하루 한 장 · 일기장
허브의 일기장 카드 또는 http://127.0.0.1:5180/diary/ 에서 실행합니다.
날짜·기분·제목·본문을 저장하고 검색, 월별 필터, 수정, 삭제할 수 있습니다.
Node.js 24 이상에서 `node server.cjs`로 실행하세요. 추가 패키지가 필요하지 않습니다.
기록 데이터베이스는 `math-gallery/data/diary.sqlite`입니다. 브라우저 저장소가 아닌 로컬 SQLite 파일에 기록합니다.
백업은 서버를 종료한 뒤 data 폴더 전체를 복사하세요. OneDrive 경로이므로 PC 설정에 따라 동기화될 수 있습니다.
서버는 127.0.0.1에서만 접속 가능하며, DB 파일은 HTTP로 제공하지 않습니다. 로그인과 암호화 기능은 없습니다.
저장 버튼을 눌러야 저장됩니다. 저장하지 않은 채 이동할 때는 확인 안내를 표시합니다.
`node --test diary/test.cjs`로 생성·재연결 후 조회·수정·삭제·날짜 검증·외부 출처 차단을 검사합니다.
