# 수학 팝! — 초5 버블 챌린지

DESIGN (2)의 파스텔 스티커 팔레트, 굵은 제목, 파란 리본 모티프, 검정 윤곽선과 둥근 버튼을 적용한 로컬 수학 게임입니다. 외부 라이브러리·폰트·이미지 요청 없이 실행합니다.

## 실행

index.html을 더블 클릭해 브라우저에서 여세요. 기존 화면이 열려 있다면 새로고침하세요.

선택 사항: Node.js가 있으면 이 폴더에서 `node server.cjs`를 실행하고 http://127.0.0.1:5173 을 여세요. 종료는 Ctrl+C입니다. 공개 배포 없이 이 컴퓨터에서만 접근하도록 설정했습니다.

## 게임 방법

- 시작 화면에서 일반 모드 또는 문제당 20초의 스피드 모드를 선택합니다.
- 8문제 중 무작위로 나온 5문제를 풉니다. 정답 버블을 클릭·터치하거나 숫자 1~4 키를 누르세요.
- 정답은 100점이며, 연속 정답마다 보너스가 20점씩 늘어납니다. 오답이나 시간 초과는 콤보만 초기화합니다.
- 각 문제의 풀이를 읽은 뒤 다음 문제로 넘어갑니다. 풀이 중에는 타이머가 멈춥니다.
- 일시 정지, 도움말, 다른 탭으로 전환할 때 시간이 멈춥니다.
- 마지막에 점수·최고 콤보와 모든 문제의 풀이를 확인할 수 있습니다.
- 동작 줄이기 운영체제 설정을 켜면 버블과 색종이 애니메이션을 생략합니다.

로그인, 기록 수집, 외부 통신, 공개 배포는 없습니다.
